# anvayya.in — static site

This repo is the complete anvayya.in website (5 plain HTML pages, no build step). Netlify publishes it directly: publish directory = root, no build command.

To edit a page: open the `.html` file on GitHub, click the pencil icon (Edit), make your change, then Commit changes. Netlify auto-deploys the site within a minute or two.

Pages: `index.html` (home), `offerings.html`, `plans.html`, `about.html`, `contact.html`. Fonts and styling load from Google Fonts and the Tailwind CDN, so no other files are needed.
